# 玩法提议

> 现状：主世界（城市 / 电动车 / 商店 / 老师 Boss / 灵魂出窍 / 聊天）+ 两个对战模式（陨石混战、疯狂抓钩）。
> 判断「无聊」的依据不是内容少，而是**玩完之后什么都不留下、也没影响过别人**。这份文档先给诊断和校尺，再给三层清单，最后是落地顺序。

---

## 一、先把「无聊」的来源说清楚

**1. 陨石混战本质是「披着 PvP 皮的 PvE」。**
所有人躲的是同一个环境危险源，玩家之间零交互。赢了只是「我躲得久 / 我运气好」。反过来看疯狂抓钩——因为能**把人从柱子上甩进岩浆**——体感明显更好。结论：刺激不来自「危险很多」，来自**「我影响了你的结果」**。

**2. 一局内没有状态翻转。**
强的人从第 10 秒强到结束，落后的人没有任何一张能翻盘的牌。没有翻盘窗口 = 后 60% 时间在等结束。

**3. 一局结束后什么都不留下。**
没有结算、没有名次、没有积累、没有「再来一局」。退房＝一切归零。

**4. 反馈是「数值级」而不是「感官级」。**
被陨石砸 200 伤害，屏幕上只少了一截血条。没有顿帧、没有震动、没有击杀播报。这是最便宜也最见效的一块。

---

## 二、三条校尺（判断一个玩法值不值得做）

| 校尺 | 问题 | 反例 |
| --- | --- | --- |
| 互动性 | 这一局里，我能改变别人的结果 ≥3 次吗？ | 陨石混战：0 次 |
| 翻盘窗口 | 落后的人手里有一张能翻盘的牌吗？ | 陨石混战：没有 |
| 累积 | 这一局结束后，我比开局多拥有些什么？ | 现在：什么都没有 |

任何新玩法提案先过这三条。三条都挂的直接砍掉。

---

## 三、提议清单

### 第 0 档 · 不新增玩法，只补刺激（性价比最高，优先做）

现有内容其实够玩，缺的是**手感**。这一档全是「几行到几十行」的改动，不引入新场景、不动协议。

| # | 提议 | 关键做法 | 复用 |
| --- | --- | --- | --- |
| 0.1 | **打击反馈三件套** | 命中时顿帧 70ms（`dt` 乘 0.1）、相机抖 120ms、屏幕闪一下 | `_changeHealth` / `_die` / 现有 `_flashEl`、`_redOverlay` |
| 0.2 | **击杀播报** | 屏幕右上滚动「张三 用棍子 把 李四 打下了岩浆」，复用聊天栏的淡出逻辑 | `ChatBox`（`add({sys:true})` 现成） |
| 0.3 | **残血心跳** | 血量 <30% 时画面边缘红晕 + 心跳音，越低越急 | `_redOverlay` 已存在 |
| 0.4 | **死亡镜头** | 被砸中时相机绕自己转一圈（2.5s）再弹「失败」，而不是瞬间定格 | `thirdPerson` 相机逻辑 |

> 这一档做完，同样的两个模式体感会明显不一样。**建议先做这一档再谈新模式。**

---

### 第 1 档 · 轻玩法（复用「房主权威 + 全场复刻」那套广播）

陨石/金币/掉落物已经把「房主生成 → 广播 → 各端本地复刻 → 只对本机结算」这条链路跑通了。下面这些**只换内容，不换机制**。

| # | 提议 | 核心循环 | 复用 | 校尺 |
| --- | --- | --- | --- | --- |
| 1.1 | **战场道具刷新** | 场地上周期刷出商店道具（抓钩/加特林/护盾/黑洞），谁捡到谁用 | `_spawnDrop` / `sendDrop` / `sendPickup` 全套已实现 | ✅互动 ✅翻盘 ✅ |
| 1.2 | **空投箱** | 每 30s 一个「快递箱」从天而降，落地冲击波把人炸开（**只击退不扣血**），箱里出一件道具 | `_spawnMeteor` 的飞行+落点圈 + `sendKnock` | ✅互动 ✅翻盘 ✅ |
| 1.3 | **安全区收缩** | 陨石混战加一个不断缩小的发光圈，圈外每 0.5s 掉血 | 竞技场边界 + 一个环 + 每帧距离判定 | ✅互动 ✅ |
| 1.4 | **死亡观战** | 死后不退房，切到第三人称跟随随机存活者，能聊天不能动 | `thirdPerson` 相机；`_pendingCombatExit` 改条件 | ✅（留住人） |
| 1.5 | **结算面板** | 名次 / 存活时间 / 造成伤害 / 吃到金币，带「再来一局」按钮 | 需要服务端在房里记一份轻统计 | ✅累积 |

---

### 第 2 档 · 新模式（复用房间 + 场景切换）

服务端的「大厅 + 多对战房 + 匹配队列」已经能承载任意模式，新增模式 = 加一个 `mode` 字符串 + 一个 `build*Arena`。

| # | 提议 | 核心循环 | 为什么值得做 | 工作量 |
| --- | --- | --- | --- | --- |
| 2.1 | **跳房子竞速** | 柱子林里从底部到顶部排一条**光点链**，抓钩只能勾下一个光点，先到顶的赢 | **最省**：光点瞄准（`_pickBeacon`）+ 抓钩落地 + 岩浆判负全是现成的，只要给光点排序并加「必须按序勾」 | 小 |
| 2.2 | **拔河** | 两队站两侧，用抓钩互相钩，把人拉过中线得分 | 抓钩钩人 + `knock` 同步已实现，只加一条中线判定 | 小 |
| 2.3 | **击鼓传花** | 一颗「点名册」在场上，持有者开始 8s 倒计时，归零就出局；抓钩能把册子塞给别人 | 强制所有人贴脸互斗，天然高互动；复用掉落物拾取 | 中 |
| 2.4 | **随堂测验** | 屏幕出选择题，四个答案平台，站错的那块塌掉 | 复用抓钩场景的柱子 + 服务端广播 | 中 |
| 2.5 | **值日生（4 人合作 PvE）** | 教室里刷粉笔怪追人，用扫把打，限时 3 分钟；**团灭才算输** | 给「合作」一个理由，现在所有模式都是各自为战 | 中 |
| 2.6 | **占座位（抢椅子）** | 教室 20 把椅子，每 15s 撤 3 把，最后站着的人赢 | 规则简单、情绪密度极高 | 中 |

### 第 3 档 · 系统层（解决「不留东西」）

| # | 提议 | 说明 |
| --- | --- | --- |
| 3.1 | **学分与称号** | 对战结算给学分，商店里换皮肤/称号/表情。本地背包体系（`getBagKey` / `addToBag`）已有，加一个 wallet 即可 |

## 四、优先级矩阵

横轴＝实现成本，纵轴＝「玩家互相影响的程度」（最直接对应「好不好玩」）。

```
互动性高 ┤  2.3 击鼓传花        1.2 空投箱 ●
         │  2.5 值日生          1.1 战场道具 ●
         │  2.1 跳房子竞速 ●    2.2 拔河 ●
         ├──────────────────────────────────────
         │  2.6 占座位          1.3 缩圈
         │  3.1 学分            1.4 观战
互动性低 ┤  3.4 编辑器联动       0.1 打击反馈 ●◀ 最该先做
         └──────────────────────────────────────
            成本高                  成本低
```

**图例**：● = 建议优先

## 五、推荐落地顺序

**第一批（不新增玩法，只补反馈）**
`0.1 打击反馈` → `0.2 击杀播报` → `0.4 死亡镜头` → `1.5 结算面板` → `1.1 战场道具`

> 这一批做完，「无聊」这个词大概率就不用再提了。因为现在缺的不是玩法，是**「我做的事有回响」**。

**第二批（低成本高互动）**
`1.2 空投箱` → `2.2 拔河` → `2.1 跳房子竞速`

**第三批（新玩法 + 长期动力）**
`1.3 缩圈` → `2.3 击鼓传花` → `3.1 学分与称号` → `2.5 值日生`

---

## 六、不建议做的（防止跑偏）

1. **继续加「躲环境」类模式**。陨石、岩浆的问题不是危险不够多，是玩家之间没有互动。再做一个「躲避激光」不会更好玩。
2. **加纯数值商品**（伤害 +1 / 血量 +50）。只会拉大差距，让翻盘窗口更小。
3. **单机化的「打一堆 NPC」**。同样的工作量不如做成 2.5 那种合作 PvE，至少能互相救。
4. **在主世界里加更多可逛的地图**。空旷的漂亮地图第二次就不新鲜了；有对手的地方才值得反复去。

---

## 附：一句话总结

> 别再加玩法了，先让**每一次出手都有回声**——顿帧、震动、播报、结算、道具；
> 然后再加一个**能直接影响别人**的模式（拔河 / 击鼓传花 / 跳房子竞速），
> 最后用**学分**把每一局串起来。
